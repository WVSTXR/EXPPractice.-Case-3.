# Система документооборота для БУ «ХМГМА»

Прототип системы электронного документооборота, разработанный в рамках производственной практики.

## Возможности

- Регистрация пользователей с ролями (admin, manager, employee).
- Создание документов.
- Отправка документов на согласование.
- Согласование и отклонение документов.
- Архивирование согласованных документов.
- Поиск по ID и по автору.
- Контроль просроченных документов.
- Сохранение и загрузка данных в JSON.

## Технологии

- Python 3.10+
- Стандартная библиотека (json, datetime)

## Запуск

```bash
python main.py
